# Security Policy

## Supported Versions

The Compute Macro Index (CMI) framework is in active development.

| Version | Supported          |
| ------- | ------------------ |
| v0.1.x  | :white_check_mark: |

## Reporting a Vulnerability

Because this repository currently hosts methodological documentation rather than executable code at the moment, traditional software vulnerabilities are unlikely. 

However, if you discover a critical exploit in the mathematical architecture, a structural flaw in the proposed data pipeline, or a security vulnerability in any future codebase releases, please do not open a public issue. 

Instead, contact the maintainer directly via direct message on X (@ComputeMacroCMI) or via the contact channels at computemacroindex.com. 

We take structural integrity seriously and will acknowledge receipt of all legitimate vulnerability reports ASAP.
